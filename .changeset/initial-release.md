First release. `bendo` is the CLI, typed client, route type generator and TanStack Query helpers. `create-bendo` scaffolds an API or full-stack app with its own copy of the Bend library. `vite-plugin-bendo` imports `.bend` files into a Vite app. The Bend library itself goes to BendHub as `bendo@0.1.0.0`.
